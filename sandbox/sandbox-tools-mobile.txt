CTF SANDBOX (MOBILE / FLUTTER) TOOLS
====================================
Image: ctf-sandbox-mobile
For Android/Flutter CTF (e.g. PWNKnight APK + libapp.so).

== Read this first ==
cat /tools.txt

== APK / DEX ==
jadx                 Java/Kotlin decompiler. jadx -d out app.apk
jadx-gui             (if DISPLAY; usually headless: jadx CLI)
apktool              apktool d app.apk -o out
unzip / zip          APK is a zip; unzip -l app.apk
aapt / aapt2         Resource dump if installed
androguard           python -c "from androguard.misc import AnalyzeAPK"

== Flutter / Dart AOT (libapp.so) ==
blutter              Dump Dart AOT objects/asm. Typical:
                       blutter /path/to/lib/arm64-v8a/ ./blutter_out
                     Needs matching libapp.so + libflutter.so directory.
/opt/blutter-pwnknight
                     Prebuilt blutter dump for PWNKnight (Dart 3.10.x).
                     Start here: ls /opt/blutter-pwnknight ; grep -R EncryptedDialogs /opt/blutter-pwnknight | head
reflutter            pip/reflutter helpers for Flutter reverse
strings / r2         Baseline string + disasm on libapp.so
pyelftools           Parse ELF snapshot symbols (_kDartIsolateSnapshotData)

== Dynamic (optional) ==
frida / frida-tools  frida -U -f pkg -l hook.js
adb                  Android Debug Bridge (device/emulator)

== Also present (pwn/rev basics) ==
pwntools, gdb+gef, r2, ROPgadget, one_gadget, patchelf,
qemu-x86_64-static (q64), python3, openssl, jq, file, xxd

== Suggested workflow for Flutter flag challenges ==
1. unzip APK → assets + lib/*/libapp.so libflutter.so
2. jadx APK for Java/Kotlin glue (often thin)
3. blutter on lib/arm64-v8a → read pp.txt / asm / objects for
   EncryptedDialogs, SecretPinDialog, EntropyBus, flag blobs
4. Reimplement crypto (HMAC/AES/xor) in python from dumped constants
5. submit_flag only with a concrete recovered ARCHA{...} / real flag
