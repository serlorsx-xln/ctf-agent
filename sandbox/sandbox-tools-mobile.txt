== ANDROID / FLUTTER ==
jadx                 Java/Kotlin decompiler. jadx -d out app.apk
apktool              apktool d app.apk -o out
unzip / zip          APK is a zip; unzip -l app.apk
androguard           python -c "from androguard.misc import AnalyzeAPK"

== FLUTTER / DART AOT (libapp.so) ==
blutter              Dump Dart AOT objects/asm. Typical:
                       blutter /path/to/lib/arm64-v8a/ ./blutter_out
                     Needs matching libapp.so + libflutter.so in that directory.
                     blutter --help for usage. Wrapper validates inputs.
reflutter            Flutter reverse helpers
strings / objdump       Baseline string + disasm on libapp.so
pyelftools           Parse ELF / Dart snapshot sections

== DYNAMIC (optional) ==
frida / frida-tools  frida -U -f pkg -l hook.js
adb                  Android Debug Bridge (device/emulator)

== ALSO USEFUL (often via pwn pack auto-ensure) ==
python3, file, xxd, jq
qemu-x86_64-static / q64   x86_64 ELFs on aarch64 (pwn pack)
pwntools, gdb+gef, ROPgadget, one_gadget, patchelf  (pwn pack)

== SUGGESTED FLOW (Flutter APK) ==
1. unzip APK → assets + lib/*/libapp.so libflutter.so
2. jadx APK for Java/Kotlin glue
3. blutter on lib/arm64-v8a → read pp.txt / asm / objects
4. Reimplement crypto/logic in Python from dumped constants
5. submit_flag only with a concrete recovered flag

== PATHS ==
/opt/jadx                jadx install
/opt/apktool             apktool jar
/opt/blutter             blutter checkout (if present)
