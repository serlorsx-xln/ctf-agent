== ARCH / EMULATION ==
uname -m                 Container arch. Challenge bins are usually x86_64.
qemu-x86_64-static       Run x86_64 ELF on aarch64. Alias: q64
qemu-i386-static         Run i386 ELF. Alias: q32
                         Wrappers auto-add -L /usr/x86_64-linux-gnu (or i686)
                         so guest libc from libc6-*-cross is found. Override
                         with QEMU_LD_PREFIX=... or pass your own -L.
file ./chal              Identify arch/ABI before running.
objdump                  On aarch64 hosts, `objdump` is wired to
                         x86_64-linux-gnu-objdump (native arm objdump cannot
                         disassemble x86_64 — "architecture UNKNOWN").
                         Explicit: x86_64-linux-gnu-objdump -d -M intel ./chal

== BINARY EXPLOITATION ==
python3 + pwntools       from pwn import *; ELF, process, remote, ROP, cyclic
gdb + gef                gdb ./chal ; checksec ; vmmap ; heap
gdb-multiarch            Cross-arch (e.g. aarch64 host → amd64 under qemu).
                         qemu-x86_64-static -g 1234 ./chal &
                         gdb-multiarch -q ./chal  # target remote :1234
checksec                 checksec --file=./chal  (pwntools)
ROPgadget                ROPgadget --binary ./chal
one_gadget               one_gadget /usr/x86_64-linux-gnu/lib/libc.so.6
                         (also /lib/x86_64-linux-gnu/libc.so.6 after pwn pack)
patchelf                 patchelf --set-interpreter --set-rpath
seccomp-tools            seccomp-tools dump ./chal
r2 / radare2             Reverse engineering. r2 ./chal
angr                     Symbolic execution. import angr
pyghidra / Ghidra        Decompiler API — loads with the ghidra pack (import pyghidra)
capstone / unicorn       Disasm / CPU emulate (Python)
strace / ltrace          Syscall / libc tracing
socat / nc               Local listeners / relays

== SUGGESTED FLOW ==
1. file + checksec on the binary
2. If aarch64 host and x86_64 bin: q64 ./chal  (or qemu-x86_64-static ./chal)
3. Find leak / overflow with cyclic + gdb/gef (gdb-multiarch + qemu -g …)
4. Identify libc ; patchelf if needed for local
5. one_gadget or ROP to system/execve — only if there is a remote/flag file
6. No connection info + reverse/misc tags: flag is usually from analysis,
   not from a shell inside the sandbox (you already have root via bash)
