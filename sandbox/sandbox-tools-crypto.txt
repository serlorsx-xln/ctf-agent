== NOTES ==
`sage` and system `python3` are different interpreters — packages do not cross.
  Algebra: `sage` (pycryptodome works inside sage).
  Networking / `pwntools`: system `python3` only — `from pwn import *` fails under sage.
  Pattern: sage computes → write results; `python3` + pwntools (or sockets) for remote I/O.
Do not put /opt/sagemath/bin on PATH (it shadows python3).
Sage is shared read-only from the host pack cache across sandboxes.
